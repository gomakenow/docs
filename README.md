# GoMakeNow Documentation

This repository contains the documentation website for **GoMakeNow**, a Go boilerplate for building applications.

The site uses [VitePress](https://vitepress.dev/) and currently contains only a starter landing page. Documentation will be added as GoMakeNow evolves.

## Local development

```bash
npm install
npm run docs:dev
```

To create a production build:

```bash
npm run docs:build
```
